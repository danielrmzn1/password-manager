Desktop app not reachable

  • Password Manager is running on this computer.
  • Its vault has been unlocked at least once since it started.
  • Settings → Browser extension has “Allow the browser extension to connect” switched on.

Pair with the desktop app

  1. Open Password Manager and unlock your vault.
  2. Go to Settings → Browser extension.
  3. Choose Pair extension to get a code.

The code is valid for two minutes and can be used once.
